This page lists one dashboard per competition. It is empty because the build found no scorecard PDFs to read.

  1. Export the scorecards you want from the Match Centre site and copy the PDFs into the data/ folder beside build.py. Folders inside it are fine, and in multi-season mode the first folder under data/ is what names the season.
  2. Run python3 build.py again. It reports every PDF it read, and names any it refused along with the reason.
  3. To see a finished dashboard before your own cards arrive, run python3 tools/demo.py. It writes a fictional club's season into data/, so build again afterwards, and delete that folder when you are done with it.

README.md in the project folder covers both paths, and what to do about a card that could not be read.
